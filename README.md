
# Portfólio Profissional

**Aluno:** Thiago Vanni Tertuliano

## Descrição

Portfólio profissional desenvolvido como atividade da disciplina Desenvolvimento de Sistemas I da ETEC EaD.

O site apresenta minha formação, experiência profissional, projetos desenvolvidos e informações de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3

## Funcionalidades

- Menu de navegação entre as seções.
- Apresentação do perfil profissional.
- Exibição de projetos em cartões.
- Links de contato por e-mail e GitHub.
- Layout responsivo para computadores e celulares.

## Funcionalidade adicional

Foi implementado um efeito visual nos cartões dos projetos utilizando CSS.

Ao passar o mouse sobre um cartão, uma sombra aparece suavemente, destacando o projeto selecionado.

A funcionalidade utiliza a pseudoclasse `:hover` e a propriedade `transition`.

## Como utilizar

1. Abra o arquivo `index.html` em um navegador.
2. Utilize o menu para navegar pelas seções.
3. Passe o mouse sobre os cartões para visualizar o efeito.
4. Acesse os links disponíveis na seção Contato.
